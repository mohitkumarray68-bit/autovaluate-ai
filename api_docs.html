POST /api/predict Primary Endpoint

Computes the estimated market value, channel pricing splits, and a 10-year depreciation trajectory for a specified vehicle configuration.

Request Headers

Content-Type: application/json
Accept: application/json

Request Payload (JSON)

Field Type Required Description
brand string Yes Manufacturer name (e.g., "Maruti", "Tata", "Hyundai")
model string Yes Model nameplate (e.g., "Swift", "Safari", "Creta")
vehicle_age integer Yes Age of the vehicle in years (1 to 20)
km_driven integer Yes Odometer kilometers driven (500 to 300,000)
fuel_type string Yes "Petrol" | "Diesel" | "CNG" | "Electric"
transmission_type string Yes "Manual" | "Automatic"
seller_type string No "Individual" | "Dealer" | "Trustmark Dealer" (Default: "Individual")
engine integer Yes Displacement in cubic centimeters (CC, e.g. 1197)
max_power float Yes Output power in brake horsepower (bhp, e.g. 82.0)
mileage float Yes Fuel economy in kmpl (e.g. 21.2)
seats integer No Passenger seat count (Default: 5)

Example cURL Request

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "brand": "Tata",
    "model": "Safari",
    "vehicle_age": 3,
    "km_driven": 40000,
    "fuel_type": "Diesel",
    "transmission_type": "Manual",
    "seller_type": "Individual",
    "engine": 2179,
    "max_power": 138.1,
    "mileage": 14.0,
    "seats": 7
  }'

GET /api/specs-lookup

Returns typical OEM factory technical specifications (engine, bhp, mileage, seats) indexed across 31 brands and models.

curl -X GET "http://127.0.0.1:5000/api/specs-lookup?brand=Maruti&model=Swift"
